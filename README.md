## UPMC (upmc)

A world-renowned health care provider and insurer headquartered in Pittsburgh, Pennsylvania. One of the largest nonprofit health systems in the United States, operating hospitals, physician practices, and a health insurance division (UPMC Health Plan) serving millions of members. UPMC Health Plan exposes an ONC 21st Century Cures Act Developer API for patient-authorized access to clinical and claims data over HL7 FHIR.

**URL:** [https://www.upmc.com/](https://www.upmc.com/)

**Health Plan:** [https://www.upmchealthplan.com/](https://www.upmchealthplan.com/)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=upmc-api-evangelist&utm_content=repo)
